# Within-Host SARS-CoV-2 Evolution During Sotrovimab Treatment in Immunocompromised Patients: A Longitudinal Genomics Analysis of Viral Diversity, Selection, and Escape Mutations

This repository contains the R scripts used for the analysis presented in my dissertation.

## Repository structure

- `scripts/` – R scripts used for data processing, statistical analysis and figure generation
- `data/` – documentation describing the input data; raw patient-level data are not included
- `results/` – selected derived analysis outputs
- `figures/` – dissertation figures

## Requirements

Analyses were performed using R and RStudio.

## Data

The underlying sequencing and patient-level data are not included in this repository.

## Reproducibility

The scripts are numbered according to the general order in which the analyses are performed.
